# Группы, участники и доступы

## Как появляется группа

Один Telegram-бот обслуживает любое количество групп. В каждой группе её
Telegram-администратор один раз выполняет `/setup`. Бот создаёт отдельное
рабочее пространство со своими участниками, напоминаниями, настройками и
историей. Человек видит в Mini App только те группы, где он активный участник.

Первый администратор, выполнивший `/setup`, становится владельцем рабочего
пространства. Глобального списка администраторов в переменных окружения нет:
права хранятся отдельно для каждой группы.

## Роли

- Владелец меняет настройки группы, назначает организаторов и может передать
  владение другому активному участнику.
- Организатор меняет настройки и создаёт групповые напоминания.
- Участник видит групповые напоминания, выполняет назначенные ему дела и может
  создавать личные напоминания для себя.

Передача владения требует отдельного подтверждения в Mini App. После передачи
прежний владелец остаётся организатором. Если владелец вышел из Telegram-группы,
другой её Telegram-администратор может выполнить `/setup`: бот восстановит
владение только потому, что прежний владелец уже неактивен.

## Как появляются участники

Telegram не даёт боту полный список участников даже с правами администратора.
Бот добавляет людей в пространство безопасными способами:

- видит новых участников по событиям вступления;
- запоминает людей, которые пишут сообщения в группе;
- при `/sync` повторно проверяет администраторов и уже известных участников;
- владелец или организатор может открыть личный чат с ботом и выбрать до десяти
  пользователей через Telegram — бот дополнительно проверит их членство именно
  в выбранной группе.

Команду `/start` в группе каждому писать не нужно. Личный `/start` требуется
только получателю личных уведомлений: Telegram запрещает боту первым начинать
диалог с человеком.

## Настройки группы

По умолчанию используются часовой пояс `Europe/Moscow`, тихие часы
`22:00–08:00` и сигнал для событий «на весь день» в `09:00`. Владелец и
организаторы меняют их в разделе «Ритм группы».

Часовой пояс становится значением по умолчанию для новых напоминаний. Уже
созданное напоминание сохраняет прежний локальный график, чтобы смена настройки
группы неожиданно не передвинула его дедлайн. Изменение настроек и владельца
попадает в журнал действий.
