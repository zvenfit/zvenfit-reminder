# Smoke test

Запускать после деплоя в production.

## 1. Webhook

```bash
curl "https://api.telegram.org/bot${BOT_TOKEN}/getWebhookInfo"
```

Ожидаем `url` = `${WEBHOOK_URL}/webhook`.

## 2. Команды бота

В разрешённой группе:

- `/start` → приветствие + кнопка Mini App
- `/list` → пусто или список правил

## 3. Кэш участников

**Важно:** privacy mode у бота должен быть выключен (`/setprivacy` → Disable в BotFather).

Каждый участник пишет сообщение в группе, затем открываем Mini App — в picker'е должны появиться имена.

## 4. Разовое напоминание

В Mini App создай правило:

- Тип: разово
- Срок: сейчас + 3 минуты (попадает в окно cron)
- Сохранить

Ждём до 5 минут → в группе сообщение с кнопками Done/Skip.

## 5. Завершение

Жмём **Done** → сообщение обновляется, instance = `done`, разовое правило уходит в архив.

Альтернатива: `/done <instance_id>` в группе.

## 6. Ежемесячное напоминание

Создай recurring-правило:

- День месяца: сегодня
- Время: текущее + 2 минуты

Ждём cron → напоминание один раз за текущий период.

Жмём **Done** → instance закрыт, правило остаётся активным на следующий месяц.
