# Smoke test

Запускать после деплоя в production.

## 1. Webhook

```bash
curl "https://api.telegram.org/bot${BOT_TOKEN}/getWebhookInfo"
```

Ожидаем `url` = `${TELEGRAM_WEBHOOK_URL}` и отсутствие свежего
`last_error_message`. Для production это прямой URL bot-функции без суффикса
`/webhook`.

## 2. Команды бота

В новой группе от имени Telegram-администратора:

- `/setup` → workspace создан, отправитель стал владельцем

В зарегистрированной группе:

- `/start` → приветствие + ссылка на личный чат с ботом
- `/list` → пусто или список напоминаний этой группы

В личном чате владельца workspace:

- `/start` → кнопка «Открыть панель» и отдельная «Добавить участников» для
  каждой группы, где пользователь владелец или организатор

## 3. Участники

Нажимаем «Добавить участников» и выбираем несколько пользователей. Backend
должен добавить только тех, кто сейчас состоит в выбранной группе. После
ответа `✅ Добавлено участников: N` открываем Mini App — добавленные имена
должны появиться в выборе ответственного.

## 3.1 Несколько групп

Добавляем бота администратором во вторую тестовую группу и выполняем `/setup`.
После `/start` в личном чате Mini App должен показать переключатель групп. Для
каждой группы проверяем отдельные списки участников и напоминаний.

Если участник с активным назначением выходит из группы, напоминание получает
статус `paused`, повторные уведомления прекращаются, а в Mini App появляется
действие переназначения на активного участника этой же группы.

Участникам не нужно отправлять `/start` для групповых напоминаний. Для личных
напоминаний получатель должен один раз самостоятельно открыть личный чат с ботом.

## 3.2 Настройки и владелец

В Mini App владелец открывает «Ритм группы», меняет тихие часы, сохраняет и
повторно открывает экран — значения должны сохраниться только для выбранной
группы. Затем выбирает тестового участника, нажимает «Передать управление» и
отдельно подтверждает действие. Новый владелец получает роль `owner`, прежний —
`organizer`.

Для проверки восстановления владелец выходит из тестовой Telegram-группы,
после чего другой Telegram-администратор выполняет `/setup` и становится новым
владельцем. Этот сценарий использовать только в одноразовой тестовой группе.

## 4. Разовое напоминание

В Mini App создай напоминание:

- Повтор: не повторять
- Срок: сейчас + 3 минуты (попадает в окно cron)
- Сохранить

Ждём до 5 минут → в группе сообщение с кнопками «Выполнил» и «+1 час».

## 5. Завершение

Жмём **Выполнил** → повторные сигналы прекращаются, occurrence становится
`completed`, в Mini App на десять минут доступна отмена выполнения.

## 5.1 Управление серией

Для повторяющегося напоминания проверяем «Изменить», «Пауза», «Продолжить» и
«Завершить». Изменение обновляет текущее незавершённое поручение и следующие
повторы, не переписывая историю. На паузе уведомления и действия текущего
поручения недоступны; «Продолжить» возвращает ещё не просроченное поручение либо
планирует ближайшую будущую дату, а «Завершить» сохраняет историю и отменяет
незакрытое поручение.

## 6. Ежемесячное напоминание

Создай ежемесячное напоминание:

- День месяца: сегодня
- Время: текущее + 2 минуты

Ждём cron → напоминание один раз за текущий период.

Жмём **Выполнил** → occurrence закрыт, напоминание остаётся активным на
следующий месяц.
